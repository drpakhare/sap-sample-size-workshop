Part 1

Biostatistics Essentials & The "Why" Behind Sample Size

Types of data — this decides everything

TypeExamplesSummary measureCommon test
Nominal (categorical, unordered)Sex, blood group, disease (yes/no)Frequency (%)Chi-square
Ordinal (categorical, ordered)Pain scale, cancer stage, LikertMedian (IQR)Mann-Whitney
Continuous (interval/ratio)Hb, BP, age, weight, FBGMean ± SD or Median (IQR)t-test / ANOVA
Why this matters: The type of your outcome variable determines which statistical test to use, which in turn determines which sample size calculator to use. Get this wrong → everything downstream is wrong.
Ask students: "What type of variable is HbA1c? What about stage of cancer? What about cure vs no cure?" Make them classify before moving on.

The Normal Distribution — when to use mean vs median

Normally distributed

Symmetric, bell-shaped

Use: Mean ± SD

Tests: t-test, ANOVA, Pearson r

Examples: Height, BP, Hb in large samples

Skewed / non-normal

Asymmetric, outliers pull the mean

Use: Median (IQR)

Tests: Mann-Whitney, Kruskal-Wallis, Spearman

Examples: Hospital LOS, income, CRP, viral load

Practical rule: For your thesis, check normality with a histogram or Shapiro-Wilk test. If skewed, use non-parametric tests. ChooseMyStat asks you this and recommends accordingly.

p-value and confidence interval — what they really mean

p-value

Probability of seeing this result (or more extreme) if there were truly no difference

p < 0.05 → "unlikely by chance alone"

p = 0.03 does NOT mean "3% chance the result is wrong"

95% Confidence Interval

Range within which the true population value plausibly lies

Narrower CI = more precise estimate

If CI for difference includes 0 → not significant

For your protocol: Always report both p-values and CIs. The CI tells the reader HOW BIG the effect is, not just whether it exists. This is what IEC reviewers want to see.

Hypothesis testing — the logic of sample size

H₀: No difference
(null hypothesis)
vs
H₁: Difference exists
(alternative hypothesis)

We collect data and ask: "Is the observed difference large enough to reject H₀?"

Two things can go wrong:

Type I Error (α)
Reject H₀ when it's true → False positive
Convention: α = 0.05
Type II Error (β)
Fail to reject H₀ when it's false → False negative
Convention: β = 0.20, so Power = 0.80
Sample size is the tool that controls both errors simultaneously. Larger n → lower chance of both errors → more reliable conclusions.

Why calculate sample size?

  • Power — Enough subjects to detect a real effect
  • Validity — Conclusions that stand up to scrutiny
  • Ethics — Not too many (wasteful), not too few (inconclusive)
  • Resources — Budget, time, and feasibility planning
An underpowered study exposes participants to risk without producing useful knowledge. An overpowered study wastes resources. Both are ethically problematic.
Emphasise that IEC/IRB reviewers will scrutinise this section. A poorly justified sample size is the #1 reason for protocol revision requests.

The four ingredients of sample size

IngredientWhat it meansConvention
α (significance level)Risk of false positive0.05 (two-sided)
Power (1 − β)Probability of detecting a true effect0.80 or 0.90
Effect sizeThe smallest difference that is clinically meaningfulFrom literature / pilot
VariabilitySD for continuous, proportions for categoricalFrom literature / pilot
Effect size is the hardest part. It must come from prior literature, pilot data, or clinical judgement — not from what gives you a convenient n.
Spend time on effect size. Ask students: "What is the smallest improvement in HbA1c that would make you change your practice?" This is the clinically meaningful difference, not the statistically detectable one.

Effect size — where does it come from?

  • Published literature — "Previous RCT found mean difference of 0.5% in HbA1c"
  • Pilot study — Your own preliminary data
  • Clinical judgement — "A difference of <5 mmHg in SBP isn't clinically relevant"
  • Standardised conventions — Cohen's d: 0.2 small, 0.5 medium, 0.8 large
For proportions: You need the expected value in each group (e.g., 15% vs 5%)
For means: You need the expected difference AND the standard deviation

One-sided vs two-sided test

Two-sided (default)

"Is there any difference?"

Drug could be better OR worse

Use this unless you have a strong reason not to

One-sided

"Is the new treatment better?"

Only interested in one direction

Needs smaller n but harder to justify to reviewers

Rule of thumb for thesis: Always use two-sided unless your guide specifically advises otherwise. Ethics committees prefer it.

What is a SAP statement?

The Statistical Analysis Plan paragraph in your protocol that justifies your sample size. It must contain:

  1. The statistical test you plan to use
  2. The expected values (effect size, proportions, means)
  3. Alpha and power
  4. The computed n
  5. Dropout adjustment (if applicable)
  6. The reference for your expected values
ChooseMyStat generates this entire statement for you in the SAP Text tab. You add the reference and it's ready for your protocol.

Anatomy of a SAP statement

"Using an independent-samples t-test (two-sided α = 0.05, power = 0.80) to detect a mean difference of 0.5% in HbA1c between the intervention and control groups, with an assumed common standard deviation of 1.2% (based on Kumar et al., 2023), a minimum of 92 subjects per group (184 total) is required. Accounting for an anticipated 15% dropout rate, the enrollment target is inflated to 217 subjects."

Notice the structure: test → parameters → n → dropout → reference

Walk through each element. Point out that this is exactly what ChooseMyStat generates — they just need to add the citation for the expected values.

The SAP is more than sample size — descriptive statistics

Every SAP must describe how you will summarise your data. Template:

"Continuous variables will be tested for normality using the Shapiro-Wilk test. Normally distributed variables will be expressed as mean ± standard deviation and compared using the independent-samples t-test (or paired t-test). Skewed variables will be expressed as median (interquartile range) and compared using the Mann-Whitney U test (or Wilcoxon signed-rank test). Categorical variables will be expressed as frequency (percentage) and compared using the chi-square test or Fisher's exact test as appropriate. A two-sided p-value < 0.05 will be considered statistically significant. All analyses will be performed using [R / SPSS / Stata] version [X]."
Tip: You can use ChooseMyStat's Descriptive pathway to determine the right summary measure for each variable, and the Inferential pathway to pick the correct test. Together they write most of your SAP.
This is often forgotten. Students write a sample size statement but not how they'll analyse the data. Stress that the descriptive stats paragraph is equally important and should come BEFORE the sample size paragraph in the protocol.

The SAP is more than sample size — inferential plan

For each objective, your SAP must also state:

  1. Primary outcome and its measurement scale (continuous / categorical / time-to-event)
  2. Statistical test — name it explicitly (e.g., "independent t-test", "chi-square", "Cox regression")
  3. Confounder handling — if applicable: multivariable regression, stratification, propensity score
  4. Multiplicity adjustment — if multiple primary outcomes: Bonferroni, Holm, FDR
  5. Missing data approach — complete case, multiple imputation, or ITT
So a complete SAP = descriptive paragraph + inferential plan per objective + sample size statement + software.
Today we'll practise the sample size piece. After the exercises, we'll see a complete SAP that ties all three blocks together.
Ethics committees and reviewers want to know: WHAT test, WHY that test, HOW you'll handle confounders, and WHAT you'll do about missing data. Most student protocols skip all of this. Setting the expectation now so the exercises feel purposeful.

The dropout adjustment

Every calculator has an "Expected dropout / non-response" field.

nadjusted = ⌈ nanalytical / (1 − dropout rate) ⌉

Example: Analytical n = 92 per group, expected 15% dropout:

nadjusted = ⌈ 92 / (1 − 0.15) ⌉ = ⌈ 108.2 ⌉ = 109 per group
The tool shows both values and includes the adjustment in the SAP text and R code automatically.
Stress that the dropout % should be based on similar studies or departmental experience, not arbitrary. Common values: 10-20% for clinical trials, 20-30% for follow-up studies.

🔬 Challenge · The Convenient-Effect Trap

How Changing Parameters Inflates or Deflates n

Using the TXA exercise (Exercise 2), change ONE parameter at a time. Use the Sensitivity Table in ChooseMyStat!

ChangeFrom → Ton per groupDirection
Base case (conservative)δ=50 mL, σ=120, α=0.05, power=80%91—
🚨 Cherry-pick large effectδ = 50 → 100 mL23↓↓↓ n drops to ¼ !

The trap: One Indian trial reports Δ = 100 mL → n = 23/group. Cherry-picking that number gives you a "convenient" n for a thesis but an underpowered study. The meta-analysis-supported Δ = 50 mL gives a realistic n = 91/group. Effect size must come from the best available evidence, not from what fits your timeline.
Give students 3-4 minutes to play with the sensitivity table. Walk around and discuss. Key insight: n ∝ 1/δ² — halving the effect size quadruples n. This is the #1 sin in sample size calculation. The TXA example makes it visceral: 23 vs 91 per group depending on which study you cherry-pick.
Exercise 3 · Case-Control Study

Tobacco Use and Breast Cancer in Indian Women

Scenario: You are planning a hospital-based case-control study to investigate the association between tobacco use (exposure) and breast cancer (outcome) in Indian women. An Indian meta-analysis (J Mid-life Health, 2025) reports a range of ORs across studies — from 1.15 to 2.0 depending on exposure definition and population. The prevalence of tobacco use among controls in your region is approximately 20%. You want 1:1 case-to-control ratio, 80% power, α = 0.05.
Note: In India, smokeless tobacco (gutka, khaini, masheri) dominates over smoking. The control exposure prevalence (20%) should ideally come from local data for your region, not national averages.

Exercise 5 · Agreement Study

USG vs MRI for Rotator Cuff Tears

Scenario: You are an MS Orthopaedics resident conducting a study on agreement between ultrasound (USG) and MRI for diagnosing rotator cuff tears (dichotomised: tear vs no tear). Putting It All Together — From Sample Size to Complete SAP

You've practised the sample size block. Now let's see the full picture.

Complete SAP — TXA in LSCS (Exercise 2)

Remember the three blocks from Part 1: descriptive + inferential + sample size. Here's what the full SAP paragraph looks like for the TXA study you just solved:

Descriptive statistics: Continuous variables will be summarized as mean ± SD or median (IQR) depending on normality assessed by Shapiro-Wilk test. Categorical variables will be presented as frequency (%).

Primary analysis: Intraoperative blood loss (mL) between TXA and placebo groups will be compared using an independent-samples t-test (or Mann-Whitney U test if non-normal). The primary outcome will be reported as mean difference with 95% CI. A two-sided p < 0.05 will be considered statistically significant.

Secondary analyses: Need for additional uterotonics (yes/no) will be compared using chi-square test. Pre- to post-operative Hb change will be compared using independent t-test. No multiplicity adjustment will be applied for secondary outcomes, which are exploratory.

Missing data: Primary analysis will follow intention-to-treat principle. Missing primary outcome data will be handled by multiple imputation if <20% missing; otherwise sensitivity analysis will be performed.

Sample size: Using an independent-samples t-test (α = 0.05, power = 0.80) to detect a mean difference of 50 mL (SD = 120 mL; Khanam et al., 2023), 91 per group are required. With 10% dropout, enrollment target = 204.

Software: All analyses will be performed using R version 4.x (R Foundation for Statistical Computing, Vienna, Austria).

Part 5

Common Mistakes, Tips & Resources

Common mistakes in sample size calculation

  1. Choosing effect size to get a convenient n — This is backwards. Effect size comes from literature/clinical judgement.
  2. Not citing the source of expected values — Always cite where p, mean, SD came from.
  3. Forgetting dropout adjustment — Analytical n ≠ enrollment target.
  4. Wrong test choice — Paired vs independent, proportions vs means — the decision tree helps here.
  5. One-sided test without justification — Reviewers will question this.
  6. Ignoring feasibility — If n = 2000 and your hospital sees 50 cases/year, you need a different approach.

Tips for writing a good SAP

  • Name the test — "Independent t-test" not "appropriate test"
  • State all parameters — α, power, effect size, variability
  • Cite your source — "(Based on Kumar et al., 2022)"
  • Show both n's — Analytical n AND enrollment target after dropout
  • Be specific — "92 per group" not "approximately 100"
Pro tip: Copy the SAP text from ChooseMyStat, add your reference, and you're done. The tool generates all the right structure.

When sample size calculation is NOT needed

  • Descriptive studies — profiling patients, describing a phenomenon
  • Pilot studies — feasibility testing (use rule of thumb: 30-50)
  • Qualitative research — saturation-based sampling
  • Case reports/series — convenience sampling
  • Census/total enumeration — you're including everyone
For these, state in your protocol: "Sample size is based on [feasibility/saturation/total enumeration] and formal sample size calculation is not applicable."
